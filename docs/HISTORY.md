# HISTORY.md（历史索引）

回答"这个仓库最近改过什么、修过哪些问题"的唯一时间线入口。完整规则见 `docs/MEMORY.md` 的「历史索引」。

- 每行一条：`日期 | 类型 | 区域 | 一行摘要 | 详情链接`；类型 ∈ `feat / fix / research / rule / arch / chore`。
- **正文只放摘要行**，细节一律链接到 `docs/exec-plans/completed/`、`docs/design-docs/` 或 spec。
- 不列入 `AGENTS.md` 路由地图——它是**检索件，不是必读件**（必读集合收敛原则）。
- 历史还"翻不过来"之前不必启用：没内容就保持空表，**别为了填满而写流水账**（见 `MEMORY.md`「别过早开层」）。
- 超过约 150 行时把最旧一年段移入 `docs/generated/history-archive-YYYY.md`。
