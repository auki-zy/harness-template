# 核心信念

这份文件是治理体系的**根**：`AGENTS.md`、`ARCHITECTURE.md` 与 `docs/` 下的规范都由它派生。条款打架时以本文件为准。

- 仓库就是 agent 的唯一事实来源。
- `AGENTS.md` 是路由器，不是百科全书。
- 验证证据比自信更重要。
- **零成本验证优先**：能用脚本 / 测试 / 类型机械检查的，不要写成每次都要读的散文（机器查 ≈ 0 token）。
- **规则要能被弄坏**：一条规则如果没有配套检查能证明它被违反过，"它被执行了"就只是一句声称。
- 反复出现的人类反馈要升级成可复用的 harness 规则，而不是在聊天里重复解释。
- 一次做好一个有边界的任务，胜过同时开很多半成品。
- 清理与简化都是交付的一部分，不是事后补救。
- 如果 agent 不能在仓库里发现某个事实，就把这个事实视为运行上不存在。
